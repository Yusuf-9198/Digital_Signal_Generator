# Full Subtractor Verilog Project

This folder contains a full subtractor module and a testbench.

## Run

Double-click `run.bat` or run from a Command Prompt:

```bat
run.bat
```

This will:

1. Compile the Verilog sources with Icarus Verilog
2. Run the testbench
3. Generate `dump.vcd` for waveform viewing

## Files

- `module.v` — full subtractor design
- `testbench.v` — testbench stimulus
- `run.bat` — one-click compile and simulation
